Tools

Small, sharp command-line tools for the jobs I kept doing by hand. Each runs from a git clone, needs nothing you don't already have, and never touches your originals.

Every tool here is also tagged spacegho-st-tools on GitHub, so this search always lists the complete set.

  • romsort

    Sort a messy ROM collection into a verified LaunchBox library: No-Intro and Redump names, duplicates folded together, card dumps merged. It's built entirely from hardlinks, so it costs no disk, and LaunchBox never breaks.

    git clone https://github.com/Spaceghost/romsort
cd romsort && ./romsort plan
